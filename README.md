# LectureCore

LectureCore — это моя система для организации и хранения учебных конспектов. Она основана на простой файловой структуре на markdown-файлах с YAML-метаданными.

Основная цель, ради которой я создал эту систему — обеспечить **простоту**, **долговечность**, **кросс-платформенность** и **машиночитаемость** моего архива конспектов.  

> **Важно:** Эта система очень и очень opinionated и разработана с учётом моих личных потребностей и сценариев использования, а также заточена под формат проведения пар в моём уч. заведении.

-----

## Быстрый старт

Для работы с хранилищем используются два основных скрипта: `add_new_subject.py` для создания нового учебного предмета и `add_new_lecture.py` для добавления конспекта.

### Шаг 1: Инициализация хранилища путём создания первого предмета

Каждый учебный предмет должен быть сначала "зарегистрирован" в системе. Это делается с помощью скрипта `add_new_subject.py`. Скрипт создаст необходимую папку и добавит запись в файл `subjects.json`.

```bash
python3 add_new_subject.py --name "Полное название предмета" --id "короткий_id"
```

  * `--name`: Полное, официальное название предмета. Оно будет использовано для создания папки.
  * `--id`: Короткий, уникальный идентификатор предмета в нижнем регистре без пробелов. Используется для связи конспектов с предметом.

**Пример:**

```bash
python3 add_new_subject.py --name "Теория государства и права" --id "тгп"
```

Эта команда добавит запись в `subjects.json` и создаст папку `./Теория государства и права/`.

### Шаг 2: Добавление нового конспекта

После создания предмета можно добавлять в него конспекты лекций или практических занятий с помощью скрипта `add_new_lecture.py`.

**Команда:**

```bash
python3 add_new_lecture.py -s <id_предмета> -t <тип> -r <аудитория> -i <номер_пары> "Название темы"
```

**Основные аргументы:**

  * `-s, --subject-id`: Короткий ID предмета, который вы добавили на предыдущем шаге (например, `"тгп"`).
  * `-t, --lecture-type`: Тип занятия. Может быть `л` (лекция) или `пр` (практика).
  * `-r, --classroom`: Номер аудитории или место проведения.
  * `-i, --absolute-lecture-id`: Порядковый номер занятия (пары) по официальному расписанию звонков.
  * `--relative-lecture-id`: Номер пары относительно порядка посещения. Например, если первую пару отменили и занятия начались со 2-ой пары, то absolute lecture id будет 2, а relative 1.
  * `"Название темы"`: Позиционный аргумент, в котором указывается тема занятия. Обязательно заключайте в кавычки, если тема содержит пробелы.

**Пример:**

```bash
python3 add_new_lecture.py -s тгп -t л -r 201 -i 3 --open "Понятие и признаки государства"
```

Эта команда создаст корректную структуру папок и файлов для нового конспекта, заполнит метаданные и, благодаря флагу `--open`, сразу же откроет созданный `.md` файл в вашем редакторе по умолчанию для наполнения.
